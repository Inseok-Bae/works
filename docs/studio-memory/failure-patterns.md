# Failure Patterns

Use this file before `spec.md`, `plan.md`, or curator memory sync.

## Known Failure Patterns

- `UI shell repeats before the concept diverges`
  - Signal: a new THOUGHT immediately turns into another field simulation with familiar overlays
  - Correction: run `form-divergence` and force a substrate change
- `Interaction count grows without narrative need`
  - Signal: multiple gestures exist, but only one actually matters
  - Correction: reduce to a trigger, threshold, or sparse perturbation if the plot is one-way
- `Time-based work never really ends`
  - Signal: drying, erasure, grief, or decay is described, but the piece keeps idling forever
  - Correction: define start, phase changes, end latch, post-end UX, and restart path in `spec.md`
- `Metrics flatten ambiguity`
  - Signal: private or interpretive states become explicit bars or counters too early
  - Correction: push those states back into traces, residue, noise, drift, or wording
- `Delayed queue becomes a habit`
  - Signal: delay is present because it worked before, not because this THOUGHT needs it
  - Correction: justify delay as a conceptual necessity or choose another causal structure
