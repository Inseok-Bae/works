# Variation Atlas

Track which formal territories are already familiar and which remain underused.

## Verified Nearby Patterns

- `bleeding-colors`
  - substrate: field-canvas
  - interaction: originally multi-gesture, later trending toward single-trigger loop
  - time model: drying / fading / one-way loop
  - shell risk: atmospheric field plus overlay text
- `violet-cloud-and-sharp-boundaries`
  - substrate: field-canvas
  - interaction: multiple gestures plus delayed queue
  - time model: slow pressure negotiation
  - shell risk: metrics panel and atmospheric field pairing

## Repeated Combinations To Watch

- field-canvas + conceptual log overlay
- delayed intention queue as the default causal engine
- atmospheric background plus explicit metrics side panel

## Underused Zones

- DOM-led typography pieces
- SVG or diagrammatic structure-first pieces
- sound-led pieces with restrained visuals
- observer-led works with distortion through looking rather than dragging
- single-trigger autonomous works that do not collapse into passivity

## Audit Rule

- Before locking a direction, compare it against this atlas and widen at least one underused zone when possible.
