# Media Families

Use these families during divergence. Pick families that differ materially, not cosmetically.

## Families

- `field-canvas`
  - Substrate: Canvas 2D or pixel field
  - Best for: diffusion, residue, weather, pressure, stains, drift
  - Risk: every piece turns into a similar atmospheric field simulation
- `dom-typography`
  - Substrate: DOM layout, text blocks, paced reveals, CSS transforms
  - Best for: memory, bureaucracy, confessions, fragmented language, documentary rhythm
  - Risk: becomes explanatory instead of experiential
- `svg-diagram`
  - Substrate: SVG graphs, maps, vectors, relations
  - Best for: structure, ideology, distance, routing, thresholds
  - Risk: becomes legible but emotionally thin
- `multi-view`
  - Substrate: coordinated panels with different resolutions of the same model
  - Best for: zoom-out and zoom-in together, public/private state separation
  - Risk: drifts into dashboard UI
- `audio-led`
  - Substrate: sound-first with restrained screen traces
  - Best for: pulses, calls, hearsay, recurrence, invisible pressure
  - Risk: underdeveloped visuals or inaccessible silent fallback
- `shader-volume`
  - Substrate: WebGL or shader-like surfaces
  - Best for: fog, unstable boundaries, density, non-object space
  - Risk: spectacle overtakes rule clarity

## Selection Rule

- Change at least one primary substrate between nearby pieces whenever possible.
- If one direction uses `field-canvas`, push the other directions toward different families.
- Do not use a family only because it is familiar. Tie it to the THOUGHT's structure.
