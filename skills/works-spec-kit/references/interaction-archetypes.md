# Interaction Archetypes

Use these patterns during divergence and spec writing.

## Archetypes

- `single-trigger-cascade`
  - Visitor role: trigger
  - Good for: plots that should start once and become irreversible
  - Risk: too little agency unless the time structure is meaningful
- `pressure-negotiation`
  - Visitor role: destabilizer
  - Good for: systems where force, holding, or persistence changes world rules
  - Risk: easily repeats as drag/hold mechanics
- `offering-withdrawal`
  - Visitor role: inviter, then leaver
  - Good for: intimacy, distance, incomplete reciprocity
  - Risk: sentimentality if cost is weak
- `commit-threshold`
  - Visitor role: decider
  - Good for: irreversible moves, hanging, sealing, sending, signing
  - Risk: empty drama if the threshold is not earned
- `observation-under-limits`
  - Visitor role: observer
  - Good for: ambiguity, delayed interpretation, uncertain metrics
  - Risk: no felt consequence if observation does not distort the field
- `ambient-perturbation`
  - Visitor role: variable inside an autonomous world
  - Good for: low-output pieces where the world mostly runs by itself
  - Risk: interaction becomes decorative

## Use Rule

- Choose the visitor role first, then the gesture.
- If the same gesture appears in two directions, make sure the role and causal structure are still materially different.
