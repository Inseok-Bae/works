# Variation Checklist

Use this checklist before locking a direction.

## Axes To Compare

- primary substrate
- spatial metaphor
- visitor role
- input density
- time model
- loop/end behavior
- layout shell
- state legibility strategy
- sound dependence
- asset dependence
- log prominence
- zoom structure

## Repeat Warnings

- `field-canvas + side metrics + multiple gestures + conceptual log` is already a strong local habit.
- `delayed queue` should not become a default reflex when a single-trigger autonomous loop is more coherent.
- `public metrics panel` can flatten ambiguity if it exposes the work too literally.
- `atmospheric fog/stain field` needs a stronger change on at least three other axes to avoid feeling like the same piece again.

## Pass Rule

- If the proposal repeats three or more axes from a recent piece, require changes before implementation.
- If the proposal introduces a new substrate but keeps the same visitor role, time model, and shell, treat it as only partial variation.
